# http.ts 상세 설명서

이 파일은 우리 앱과 서버(데이터가 저장된 곳) 사이의 **'우체국'**이나 **'통신 장비'** 역할을 합니다. 서버에 데이터를 달라고 요청하거나, 우리가 만든 데이터를 보낼 때 사용합니다.

---

## 1. 통신 도구 가져오기

```tsx
1: import ky from 'ky';
```
- **설명:** `ky`라는 이름의 통신 전문 도구를 가져옵니다. 이 도구는 서버에 편지를 보내고 답장을 받는 일을 아주 잘합니다.

---

## 2. 공통 설정 만들기 (api)

매번 주소를 적기 귀찮으므로, 기본적인 설정들을 미리 해둡니다.

```tsx
4: export const api = ky.create({
```
- **설명:** `api`라는 이름으로 우리만의 통신 설정을 하나 만듭니다. 앞으로는 이 `api`를 통해서 서버와 대화하게 됩니다.

```tsx
5:     prefixUrl:  'http://localhost:3000',
```
- **설명:** 서버의 기본 주소입니다. 모든 요청은 이 주소로 시작됩니다. (마치 전화번호의 국번이나 앞번호를 미리 저장해두는 것과 같습니다.)

```tsx
7:     headers: {
8:         'content-type': 'application/json',
9:     },
```
- **설명:** 서버에 보낼 메시지의 형식을 알려줍니다. "우리는 `JSON`이라는 형식으로 데이터를 보낼 거야!"라고 말하는 것입니다.

---

## 3. 훅(Hooks) 설정 - 중간에서 가로채기

편지를 보내기 직전이나 답장을 받은 직후에 자동으로 실행될 일들을 정해둡니다.

### (1) 요청 전 (Before Request)

```tsx
14:         beforeRequest: [
15:             (req) => {
```
- **설명:** 서버로 편지를 **보내기 직전**에 이 코드가 실행됩니다.

```tsx
18:                 const token = localStorage.getItem('accessToken');
```
- **설명:** 브라우저의 저장소(`localStorage`)에 보관된 '로그인 열쇠'(`accessToken`)가 있는지 확인합니다.

```tsx
19:                 if (token) {
20:                     req.headers.set('Authorization', `Bearer ${token}`);
21:                 }
```
- **설명:** 만약 열쇠가 있다면, 편지 봉투 외부에 "이 사람은 인증된 사람입니다"라는 표시(`Authorization`)를 붙여서 보냅니다.

### (2) 응답 후 (After Response)

```tsx
25:         afterResponse: [
26:             (_req, _opt, res) => {
```
- **설명:** 서버로부터 답장을 **받은 직후**에 이 코드가 실행됩니다.

```tsx
28:                 if (res.status === 401) {
```
- **설명:** 서버가 "너 로그인 안 되어 있어!" 또는 "열쇠가 만료됐어!"(401 에러)라고 답하면 실행됩니다.

```tsx
29:                     console.log('로그인이 만료되었습니다.');
30:                     localStorage.removeItem('accessToken');
31:                 }
```
- **설명:** 화면에 경고 메시지를 찍고, 쓸모없어진 '로그인 열쇠'를 저장소에서 삭제합니다.
