# auth.ts 상세 설명서

이 파일은 우리 서비스의 **'로그인 담당자'**입니다. 사용자가 입력한 정보를 서버로 보내서 "이 사람 로그인시켜줘!"라고 요청하는 일을 합니다.

---

## 1. 통신 도구 가져오기

```tsx
1: import { api } from './http'
```
- **설명:** 아까 `http.ts`에서 미리 만들어두었던 '통신 장비'(`api`)를 가져옵니다.

---

## 2. 로그인 함수 정의 (login)

```tsx
5: export const login = async (email:string, password:string) => {
```
- **함수 이름:** `login`
- **인수(받는 정보):**
    - `email`: 사용자가 입력한 이메일 주소 (글자 형태)
    - `password`: 사용자가 입력한 비밀번호 (글자 형태)
- **특징:** `async`(에이싱크)라는 글자가 붙어 있는데, 이는 "서버의 답장이 올 때까지 잠시 기다려야 하는 작업"이라는 뜻입니다.

```tsx
6:     return await api.post('signin', {
```
- **설명:** 서버의 `signin`(로그인) 주소로 편지를 보냅니다.
    - `post`: 데이터를 서버로 '보낸다'는 뜻의 방식입니다.
    - `await`: 서버가 답장을 줄 때까지 이 줄에서 잠시 기다립니다.

```tsx
7:         json: { email, password }
```
- **설명:** 보낼 편지 내용에 이메일과 비밀번호를 담습니다.

```tsx
8:     }).json(); 
```
- **설명:** 서버에서 답장이 오면, 그 답장을 우리가 읽기 쉬운 데이터 형식(`json`)으로 변환해서 결과값으로 돌려줍니다.

---
