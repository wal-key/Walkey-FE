# main.tsx 상세 설명서

이 파일은 우리 프로그램의 **'시작 버튼'**이자 **'뿌리'**입니다. 웹사이트가 켜질 때 브라우저가 가장 먼저 읽어서 화면을 그리기 시작하는 곳입니다.

---

## 1. 재료 가져오기 (Import)

```tsx
1: import React from 'react'
```
- **설명:** 웹 화면의 부품(컴포넌트)을 만들고 관리하는 가장 기본 도구인 `React`를 가져옵니다.

```tsx
2: import ReactDOM from 'react-dom/client'
```
- **설명:** 우리가 만든 리액트 코드를 실제 웹 브라우저의 HTML 문서에 '그려주는' 역할을 하는 도구인 `ReactDOM`을 가져옵니다.

```tsx
3: import App from './App'
```
- **설명:** 아까 우리가 보았던 '중앙 통제실'인 `App.tsx` 파일을 가져옵니다. 여기서부터 모든 화면이 시작됩니다.

```tsx
4: import './index.css'
```
- **설명:** 웹사이트의 디자인(색상, 글자 크기, 배치 등)을 담당하는 스타일 시트 파을을 가져옵니다.

---

## 2. 화면에 그리기 (Rendering)

```tsx
6: ReactDOM.createRoot(document.getElementById('root') as HTMLElement).render(
```
- **설명:** 이 줄은 아주 중요한 명령입니다.
    - `document.getElementById('root')`: 웹 브라우저의 기본 HTML 문서(index.html) 안에서 "root"라는 이름을 가진 자리를 찾습니다. (마치 빈 도화지를 찾는 것과 같습니다.)
    - `createRoot`: 리액트가 그 자리에 그림을 그릴 수 있도록 준비합니다.
    - `.render(...)`: 괄호 안에 있는 내용들을 실제로 화면에 그려넣으라는 명령입니다.

```tsx
7:     <React.StrictMode>
```
- **설명:** 코드가 잘못 작성되지는 않았는지, 더 좋은 방법은 없는지 리액트가 꼼꼼하게 검사하며 실행해주는 '엄격 모드'입니다. 실제 기능에는 영향을 주지 않지만, 개발할 때 도움을 주는 안전장치입니다.

```tsx
8:         <App />
```
- **설명:** 위에서 가져온 `App` 컴포넌트를 실행합니다. 이제 `App.tsx`에서 설정한 대로 주소에 맞는 화면들이 이 자리에 나타나게 됩니다.

```tsx
9:     </React.StrictMode>,
10: )
```
- **설명:** 열었던 '엄격 모드'와 `render` 명령을 닫아주며 마칩니다.

---

## 요약
이 파일은 딱 한 번 실행되며, **"HTML에 있는 'root' 자리에 가서 우리 앱(`App`)을 그려라!"**라는 핵심 임무를 수행합니다.
