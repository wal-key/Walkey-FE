# LoginModal.tsx 상세 설명서

이 파일은 사용자가 서비스를 시작하기 위해 거쳐야 하는 **'로그인 모달 부품'**입니다. 랜딩 페이지에서 버튼을 눌렀을 때 부드러운 애니메이션과 함께 나타납니다.

---

## 1. 주요 기능

### 부드러운 애니메이션 (`useEffect`)
- 모달이 열리고 닫힐 때 투명도(`opacity`)와 크기(`scale`) 변화를 주어 세련된 사용자 경험을 제공합니다.
- `shouldRender` 상태를 통해 모달이 닫히는 애니메이션이 끝난 후 완전히 제거되도록 설계되었습니다.

### 소셜 로그인 버튼 목록
- 네이버, 카카오, Google, GitHub 등 다양한 소셜 로그인 옵션을 제공합니다.

---

## 2. 화면 구성

### 오버레이 및 백드롭
- 배경을 어둡게 처리하고, 배경 클릭 시 모달이 닫히도록 설정되어 있습니다.

### 핵심 내용 (`glass-panel`)
- 서비스의 톤앤매너에 맞게 반투명한 유리 느낌의 디자인이 적용되었습니다.

```tsx
56:                     <a href="http://localhost:5173/walk-setup">산책 설정으로 이동</a>
```
- **참고:** 현재 테스트를 위해 바로 산책 설정 페이지로 넘어갈 수 있는 임시 링크가 포함되어 있습니다.

---

## 요약
이 컴포넌트는 **"비로그인 사용자가 서비스에 진입할 때 소셜 로그인 수단을 선택할 수 있게 돕는 세련된 애니메이션 모달창"**입니다.
