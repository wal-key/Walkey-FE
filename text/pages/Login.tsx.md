# Login.tsx 상세 설명서

이 파일은 모달 형태가 아닌 별도의 **'로그인 전용 페이지'**입니다. 모달과 유사한 기능을 수행하지만 독립적으로 존재합니다.

---

## 1. 디자인 특징

### 배경 장식 (`bg-deco`)
- 페이지의 심미성을 높이기 위해 배경에 두 개의 장식용 원형 요소를 배치했습니다.

### 중앙 로그인 카드 (`login-card`)
- `glass-panel` 스타일을 사용하여 유리 질감의 세련된 카드 형태를 띠고 있습니다.

---

## 2. 주요 기능

### 뒤로 가기 (`navigate(-1)`)
- 왼쪽 상단의 화살표 버튼을 누르면 이전에 머물렀던 페이지로 돌아갑니다.

### 소셜 로그인 인터페이스
- 네이버, 카카오, Google, GitHub 버튼이 리스트 형태로 정렬되어 있습니다.

---

## 요약
이 페이지는 **"모달을 거치지 않고 직접 로그인 경로로 들어온 사용자에게 제공되는 독립적인 로그인 화면으로, 심미적인 배경 디자인과 소셜 로그인 접근성을 강조한 페이지"**입니다.
